用 GitHub Actions 打 Mac 包（你在 Windows 上操作）
================================================

前提：注册一个免费 GitHub 账号：https://github.com/signup


第一步：把项目放到 GitHub
------------------------
方式 A（用网页，最省事）
1. 打开 https://github.com/new
2. Repository name 填例如：fabric-inventory（随便起名）
3. 选 Public（公开仓库免费额度够用；Private 也可以，免费账号每月有限额）
4. 不要勾选 Add README（本地已有文件）
5. 点 Create repository
6. 按仓库页面提示的「uploading an existing file」：点 uploading an existing file，
   把本文件夹里这些文件拖上去（不要上传 库存数据.db、dist、build）：
   - main.py
   - database.py
   - export.py
   - requirements.txt
   - build_mac.sh
   - build.bat
   - 启动.bat
   - 使用说明.txt
   - .gitignore
   - .github/workflows/build-mac.yml   （整个 .github 文件夹都要带上）
7. 点 Commit changes

方式 B（用命令行，需已安装 Git）
在本项目目录打开终端，执行（把 YOUR_NAME / REPO 换成你的）：

  git init
  git add .
  git commit -m "布料出入库初版"
  git branch -M main
  git remote add origin https://github.com/YOUR_NAME/REPO.git
  git push -u origin main

（首次 push 会让你登录 GitHub）


第二步：在网页上点一下，让云端 Mac 打包
------------------------------------
1. 打开你的仓库页面
2. 点顶部 Actions
3. 左侧点「打包 Mac」
4. 右侧点「Run workflow」→ 再点绿色「Run workflow」
5. 等几分钟，任务变成绿色对勾
6. 点进这次运行记录
7. 拉到页面最下面 Artifacts，下载：
   - 布料出入库-mac-apple-silicon   → 给 M1/M2/M3 Mac
   - 布料出入库-mac-intel           → 给 Intel Mac
8. 解压得到「布料出入库.app」，发给亲戚即可


第三步：亲戚怎么打开
--------------------
1. 把 .app 放到一个文件夹（例如「布料出入库」）
2. 双击打开；若提示无法验证开发者：
   右键图标 → 打开 → 仍要打开
3. 数据文件「库存数据.db」会出现在 .app 旁边，备份就复制这个文件


以后改了代码怎么再打一包
------------------------
1. 把改动的文件重新上传/ push 到 GitHub
2. 再走「第二步」点一次 Run workflow
3. 下载新的 zip 发给亲戚（提醒对方用新 .app，旧的 db 可以留着继续用）


常见问题
--------
Q：Actions 里没有「打包 Mac」？
A：确认仓库里已有 .github/workflows/build-mac.yml，刷新页面后再看。

Q：打包失败？
A：点进红色失败的那次，看红色日志；把报错发我即可。

Q：不知道亲戚是 Intel 还是苹果芯片？
A：让对方：左上角苹果菜单 → 关于本机 → 看芯片/处理器。
   M1/M2/M3/M4 = 下 apple-silicon；写着 Intel = 下 intel。

Q：Public 和 Private？
A：只是自己和亲戚用、不怕代码公开 → Public 最省事。
   不想公开代码 → Private，一般偶尔打包也够用。
