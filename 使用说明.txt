亿宝麦 — 使用说明
========================

一、怎么打开（本机开发）
- Windows：双击「启动.bat」，或执行 python main.py
- Mac：在终端进入本目录，执行 python3 main.py

二、打包给别人用
【重要】Windows 只能打 Windows 包，Mac 只能打 Mac 包，不能互相打包。

1）给 Windows 用户
   - 在 Windows 电脑上双击 build.bat
   - 把 dist\亿宝麦 整个文件夹拷给对方
   - 对方双击「亿宝麦.exe」

2）给 Mac 用户（推荐：你在 Windows 用 GitHub 云端打包）
   - 按同目录「GitHub打Mac包步骤.txt」操作
   - 在 Actions 里点「打包 Mac」→ 下载 zip → 发给亲戚
   - 对方双击打开；若提示无法验证：右键 → 打开 → 仍要打开

3）给 Mac 用户（备选：手上有 Mac 时本地打）
   - 安装 Python3 后执行：chmod +x build_mac.sh && ./build_mac.sh
   - 把 dist/亿宝麦.app 发给对方

三、三个表
1. 商品基础信息表：先建档（商品类型、商品编号、长度、颜色、单价可空）
2. 出入库流水表：记每一笔入库/出库，数量单位是「米」
3. 库存汇总表：按米数自动汇总（入库减出库），不用手填

四、常用操作
- 顶部「新增布料」→ 建档案
- 「新增入库 / 新增出库」→ 选布料，填米数
- 出库米数超过当前库存时会拦住（多半是之前记错了）
- 「导出 Excel」→ 一次导出三张表
- 「扩展列」→ 以后要加门幅、克重等，可在这里加列

五、数据在哪
- Windows：程序文件夹里的「库存数据.db」
- Mac：和「亿宝麦.app」放在同一文件夹里的「库存数据.db」
- 备份：复制这个 db 文件即可
- 换电脑：程序 + db 一起拷走
